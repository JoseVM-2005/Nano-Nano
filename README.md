# Nano-Nano
Code developed and used for the MEFT Nanotechnology and Nanoelectronics couse homeworks at IST.
Each folder corresponds to an assignment and contains contributions from multiple authors, including: Alice Duarte, Beatriz Gonçalves, Gonçalo Rosa and José Miguel.
Some code was developed with the use of AI, including Claude and ChatGPT, and checked by the authors.
